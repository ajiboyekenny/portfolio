# Task 1 — Responsive Portfolio Landing Page

A responsive personal portfolio for **Kehinde Ajiboye**, built with semantic HTML, CSS Grid/Flexbox, and vanilla JavaScript.

## Features
- Mobile-first responsive navigation
- Smooth section navigation
- About, skills, real featured work, and contact sections
- Genuine Nexora live-site and source-code links
- Direct link to Task 2
- SEO title, description, Open Graph, and Twitter metadata
- Accessible labels, focus states, and reduced-motion support

## Run locally
Open `index.html` in a browser. No installation is required.

## Files
- `index.html` — semantic page structure and metadata
- `style.css` — purple, light-blue, and white responsive design
- `script.js` — accessible mobile navigation
- `assets/nexora-preview.jpg` — screenshot captured from the real Nexora live site
